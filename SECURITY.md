# Security Policy

## Supported Versions

CodeSense receives security patches and updates on the latest release versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The CodeSense development team takes security seriously. If you discover a security vulnerability within CodeSense, please follow these steps:

1. **Do NOT publicly disclose the issue** in open GitHub issues, pull requests, or community discussions.
2. **Email details** to `security@codesense.dev` or use GitHub's [Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability).
3. Include:
   - Description of the vulnerability.
   - Exact steps or minimal proof-of-concept to reproduce the behavior.
   - Any potential remediation steps you recommend.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide an initial assessment and timeline for remediation within **5 business days**.
- Once a fix is verified, a patched release will be published and credit awarded to the reporter (unless anonymity is requested).

Thank you for helping keep CodeSense and its users secure!
